# Python Week 7 Assignment – File Handling and CSV Reports

## Assignment Description

This assignment demonstrates Python file handling, reading and writing text files, working with CSV files, and handling missing files safely.

## Files Included

- `my_notes.py` – Writes, appends, reads, and counts notes in a text file.
- `my_notes.txt` – Stores the four notes generated by the Python program.
- `report_builder.py` – Reads learner information from a CSV file and generates a report.
- `hubs.csv` – Contains learner names, hubs, and scores.
- `report.txt` – Contains the generated learner report.
- `README.md` – Describes the assignment and explains the file handling concepts.

## Question: What would happen if you changed "a" to "w" in Question 1?

Changing `"a"` to `"w"` would cause Python to overwrite the existing file instead of adding new information. The first three notes would be erased and replaced with the fourth note.

## Conclusion

This assignment demonstrates how Python can safely create, write, append, and read files while handling errors such as missing files.
